隐私政策

产品名称：PrivateNote（工程名 DiaryMaker）
生效日期：2026-10-26 · 最后更新：2026-10-26
公开地址：https://cfeat.github.io/DiaryMaker/privacy/

本文描述本应用如何处理与日记相关的信息。技术约束以仓库内 PRIVACY_ARCHITECTURE.md 为准；若商店页摘要与本文冲突，以更严格、保护用户的表述为准。

1. 我们是谁

PrivateNote 是一款本地优先的私人日记应用。开发者不提供托管日记内容的官方云服务，也不运营用于读取您日记正文的后端。

2. 数据存储在哪里

2.1 本机

  • 日记内容保存在您的设备上，并使用库级加密的 SQLite（SQLCipher 兼容方案）。
  • 解锁数据库与同步的密钥材料通过系统安全能力保存（Android Keystore、iOS/macOS Keychain、Windows Credential Manager），不会以明文写入普通偏好设置。

2.2 可选同步（由您提供的 WebDAV）

  • 同步完全可选。仅当您填写 WebDAV 地址与凭证并启用同步时，应用才会联网传输同步相关数据。
  • 上传内容为客户端 AES-256-GCM 加密后的密文；加解密均在设备完成。
  • 服务器由您选择与控制。开发者接触不到日记明文，也不会收到官方备份副本。

3. 我们不收集什么

  • 不通过分析、广告、崩溃上报或会话回放 SDK 收集使用行为；
  • 不建立用于浏览日记内容的账号体系或官方内容服务器；
  • 不出售个人信息；
  • 不将日记明文上传到开发者控制的服务器。

本地 PIN 与（在支持的移动设备上）生物识别仅用于本机解锁；生物特征模板由操作系统管理，应用不会上传给开发者。

4. 权限与系统能力

  • 网络访问：仅用于您配置的 WebDAV 同步；
  • 生物识别 / 锁屏认证：用于解锁应用，数据留在设备侧。

5. 数据删除与导出

  • 可在应用内删除日记条目。
  • 若曾启用 WebDAV，远程密文清理取决于同步删除与您对 WebDAV 的管理；开发者无法代为登录删除。
  • 卸载应用通常会移除本机应用数据。

6. 儿童与适用对象

本应用面向需要私人日记的一般用户，并非专为儿童设计的服务。

7. 政策变更

若数据处理方式发生实质变化，我们会更新本文并调整商店披露。请以「最后更新」日期为准。
